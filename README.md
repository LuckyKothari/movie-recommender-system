# 🎬 Movie Recommender System

A movie recommendation system built using **Python**, **Machine Learning**, **FastAPI**, and **MongoDB**.

The system recommends movies based on their similarity using movie features such as genres, keywords, cast, crew, and other metadata.

## 🚀 Features

- 🎥 Movie recommendations
- 🤖 Machine Learning-based recommendation
- 🔍 Movie search
- ⭐ Movie details
- 🎯 Similar movie recommendations
- ⚡ FastAPI backend
- 🍃 MongoDB database
- 📡 REST API

## 🛠️ Technologies Used

- Python
- FastAPI
- MongoDB
- Scikit-learn
- Pandas
- NumPy
- Uvicorn
- Git & GitHub
